01 / FIRST PRINCIPLES

BP 的判断链路

INPUT

业务目标

增长、效率、商业化、产品化、技术突破、组织收缩或新战场投入。

DIAGNOSE

组织瓶颈

是缺能力、缺结构、缺流程、缺激励、缺管理，还是战略还没有被翻译成组织动作。

DESIGN

人才系统

招聘、盘点、绩效、发展、继任、激励和变革动作需要形成同一套闭环。

03 / PRIORITY

补齐顺序

优先级 模块 核心原因 阶段产出
P0 组织诊断 + 业务理解 决定你是否能从接需求升级为判断组织问题。 业务目标 / 组织瓶颈 / 能力缺口分析表
P1 人才管理 + 组织行为学 把招聘经验延伸到绩效、发展、保留、冲突和影响力。 人才盘点、九宫格、组织场景复盘卡
P2 劳动关系合规 + 变革管理 守住敏感动作边界，并支撑组织调整真正落地。 风险检查清单、变革沟通节奏表
04 / ROADMAP

三阶段学习路径

PHASE 01 / 0-30 天

建立 BP 视角

集中补组织诊断、业务模型、HC planning、人效、预算和关键经营指标。

PHASE 02 / 31-90 天

打通人才管理

把招聘经验延伸到人才盘点、绩效校准、继任计划、职级和能力模型。

PHASE 03 / 90 天后

形成组织影响力

沉淀组织行为、劳动关系和变革案例，围绕 AI 团队建立差异化判断模型。
