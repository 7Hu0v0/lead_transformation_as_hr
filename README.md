# HR如何给组织带来变革：First Principles HRBP Lab

一个用于个人 Work 项目的静态可阅览网页，记录从招聘转型到 HRBP/BP 的理论补齐路径。

主题定位：**第一性原理**。页面把招聘到 BP 的转型拆成“业务目标 - 组织瓶颈 - 人才系统”的判断链路，先做在线静态阅览和浏览器本地编辑，后续再考虑后端、账号和云端同步。

## 功能

- 科技风、像素风单页网页
- 六大模块：组织诊断、业务理解、人才管理、组织行为学、劳动关系合规、变革管理
- 第一性原理判断链路：业务目标、组织瓶颈、人才系统
- 优先级表：P0 / P1 / P2
- 三阶段路线图：0-30 天、31-90 天、90 天后
- 可勾选学习清单，自动计算进度
- 可编辑笔记区和第一性原理画布
- 浏览器 `localStorage` 本地保存

## 本地使用

直接打开 `index.html` 即可使用。

也可以启动静态服务：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 在线部署

项目包含 GitHub Pages 工作流。推送到 `main` 后，GitHub Actions 会发布静态网页。

发布后访问地址通常是：

```text
https://7hu0v0.github.io/lead_transformation_as_hr/
```

## 保存说明

当前版本不包含后端。清单、笔记和画布内容只保存在当前浏览器的 `localStorage` 中。更换设备、浏览器或清理浏览器数据后，本地记录不会自动同步。
