# 从招聘转型到 HRBP/BP

一个用于个人 Work 项目的交互式 HTML 积累笔记，记录从招聘转型到 HRBP/BP 需要补齐的理论框架、学习路径和 AI Talent BP 差异化定位。

## 内容结构

- 六大模块：组织诊断、业务理解、人才管理、组织行为学、劳动关系合规、变革管理
- 优先级表：P0 / P1 / P2 的学习顺序与产出物
- 三阶段路线图：0-30 天、31-90 天、90 天后
- 可勾选学习清单：进度会自动计算
- 笔记区：按主题记录观察、案例和待验证问题，自动保存到浏览器本地

## 使用方式

直接打开 `index.html` 即可使用。

也可以在本地启动一个静态服务：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 本地保存说明

学习清单和笔记使用浏览器 `localStorage` 保存，只保存在当前浏览器和当前设备中。清理浏览器数据后，本地记录会被删除。
